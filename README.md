# Hostel-Complaint-Portal-Project
A full-stack hostel complaint management system built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Features
* User Registration
* User Login
* Complaint Submission
* Admin Dashboard
* Complaint Status Management
* Delete Complaints
* Responsive Modern UI

## Tech Stack
* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB

## How To Run

### Backend
```bash
npm install
node server.js
```
### Frontend
Open `index.html` using Live Server.
